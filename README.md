## Cómo ejecutar el proyecto
1. Crea y activa un entorno virtual (Windows PowerShell):
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```
o en linux:
```bash
python3 -m venv venv
source venv/bin/activate
```
2. Instala las dependencias:
```bash
pip install -r requirements.txt
```
3. Ejecuta el script:
```bash
python main.py
```
